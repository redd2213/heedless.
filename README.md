## About
 
 
**Heedless** is a 2D pixel-art metroidvania about exploring an abandoned church to reach a girl who's run out of places to run. Between you and her: every monster the building forgot to let die.
 
## Story
 
> You watch the girl disappear through the abandoned church doors, the werewolf close behind her.
>
> Something stirs in your chest.
> It's not courage, not duty,
> just the simple certainty that you cannot walk away.
>
> Your fists are clenched and your feet are already moving.
> Find her and bring her home safe.
 
## Features
 
- **Simple Combat & Movement** - Skip the complicated combos and magic. This monk knows perfectly how to punch your way thru the enemies you'll find in the abandoned levels.
- **Replay System** - Pulled off an amazing run? The game features a custom-built, state-based replay architecture that perfectly records your movements so you can watch your run again.
- **Gloomy Gothic Atmosphere** - Soundtrack and textures match the same vibe.
 

## Controls
 
| Input | Action |
|:---:|:---|
| `W` `A` `S` `D` | Move |
| `Space` | Attack |
| `Esc` | Skip cutscene |
 
## Installation

**Requirements:** Java 21+ and IntelliJ IDEA installed on your machine.

1. Clone the repository:
```powershell
git clone https://github.com/redd2213/heedless.
```
2. Open the project in IntelliJ IDEA.
3. Let Gradle sync dependencies automatically.
4. Run the `Lwjgl3Launcher` class inside the `lwjgl3` module.

## Built With

**Core Engine & Language**
- Java - The core programming language.
- LibGDX - The underlying cross-platform Java game development framework.

**User Interface & Graphics**
- Scene2D / Scene2D.UI - Used for the HUD, contextual tutorial overlays, and screen transitions.
- SpriteBatch & TextureRegions - Used for rendering and animating 2D pixel-art spritesheets.

**Data & Architecture**
- SQLite - Used for Local database management.
